# 设计提案：数字放大机（只暴露 CYM）

> 2026-10-03 由用户提出：「能否把光学放大这一套流程数字化，用户只需要调整 CYM，其余不用管？」
> 这一页是设计说明，**尚未实现**。

## 1. 这个想法从哪来

按胶片最初的思维，**颜色并不存在「科学不科学」一说**：

- 以前展现胶片靠**光学放大**；
- 负片的特性曲线与不同相纸的特性曲线**并非完全吻合**；
- 传统放大流程里，操盘的人要自己调 **CYM 滤色片**、打试条、试色彩。

所以「正确的颜色」在暗房里从来不是唯一的 —— 这正是 V777 说的「**原色集**」：
六自由度里的一切都是科学的。

**但可以拆成两层看：**

| 层 | 有没有科学一说 |
|---|---|
| 「这张片子像不像、好不好看」 | **没有**，这是审美 |
| 「把 CYM 往哪边拧，画面会变成什么样」 | **有，而且是确定性的** |

本项目做的是**第二层**：把输入的物理测准，让审美在一个干净的起点上发生。

## 2. 暗房里真正能调的只有三样

- **CYM 滤色片** → 三个 gain
- **曝光时间 / 灯泡** → 一个整体水平
- **相纸型号** → gamma（暗房里**调不了连续的 gamma**，只能换相纸）

V777 原话：「rgb 三个通道的 gain 和 gamma（**暗房中貌似并不能控制 gamma，
但可以通过选择相纸来做出变化**）」。

**三加一，正好就是「原色集」六自由度里去掉 gamma 之后剩下的部分。**

## 3. 这件事行业里早就有名字：Printer Lights

电影洗印里，每个镜头的配光单位就是 **printer lights**（加色印片机 **TAPE 25-25-25**）；
LAD 控制片就是打在 TAPE 25-25-25 这个中点上的；**NexFilm 的 Develop 面板里就有一项叫
「Printer Lights」**。本项目文档第 9 节记的 Cineon 流程，核心操作也是配光。

**用户独立想到的，与电影工业的配光流程是同一件事。**

## 4. 映射到本项目的数学

现有管线（`app/NegMath.m`）：

```
Pi_c = −log10( T_c / T0_c )                    ① 相对零点的密度
L_c  = ( Pi_c − o_c ) / γ_c − L_ref            ② 去色罩 + 通道对齐（自动）
out  = 10^( L_c / γ_paper ) − 1                ③ 输出曲线（相纸）
```

三个用户控制**恰好落在已有的三个量上**：

| 用户的控制 | 物理含义 | 数学位置 |
|---|---|---|
| **CYM 三个滑杆** | 印片机的三色滤色片 | `L_c → L_c − d_c`（在 L 上加逐通道常数） |
| **曝光** | 灯泡亮度 / 时间 | 整体平移 `L_ref`（已有） |
| **相纸型号** | 用哪种正片 / 相纸 | 输出曲线的 γ 与形状（现在写死 0.6） |

**关键性质：CYM 是加在 L 上的常数，与本项目的 `o_c` 完全同构。**
所以「CYM 归零」天然等于「标定出来的中性点」—— 用户从**有物理意义的中性起点**开始调，
而不是从一堆没有参照的滑杆开始。

方向约定（与暗房一致）：**加红滤色 → 画面变青**，即 `d_R > 0` 时红通道的曝光的减少量更大。

## 5. 「其余不用管」能做到什么程度

| | 状态 |
|---|---|
| 去色罩、通道对齐、零点 | ✅ 全自动（由标定保证） |
| CYM / 曝光 / 相纸 | ✅ 用户的**全部**可见控制，共四个半 |
| **饱和色上的残余** | ⚠️ **做不到** |

最后一条必须写在界面上：**CYM 是 3 个数，它只能改「整体偏色」，
改不了「逐颜色的误差」**（也就是本项目尚未实现的 3×3 交叉项）。
拿 CYM 去拧它治不了的问题，只会把中性一起拧坏。

## 6. 待定问题（实现前要定）

1. **CYM 的零位定义**：是「标定中性点」还是「胶片片基」？（建议前者，且界面上标明）
2. **单位**：用密度（0.01 D 一档）还是用电影界的 **printer point**（≈0.025 log E）？
   建议 printer point，好和行业资料对照。
3. **相纸预设**：给几个（Kodak 2383 / Endura / 线性）还是先只给一个可调 gamma？
4. **逐帧还是整卷**：暗房的配光是**逐镜头**的，所以 CYM 应当逐帧，
   而 γ 与零点保持「一次标定 / 逐帧零点」的现有分层。
5. 现有「黑点」滑杆怎么处理：并入曝光，还是保留为独立的抬黑？（建议并入）
